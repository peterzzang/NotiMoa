NotiMoa - Privacy Policy

Package Name: app.noti.moa | Effective Date: November 1, 2026

🔒 NotiMoa does not use INTERNET permission. All notification data is stored solely in the encrypted database on your local device and is never transmitted to external servers.

1. Purpose of Processing Personal Data

NotiMoa (hereinafter referred to as "the App") processes data solely to store, search, analyze statistics, and manage blocked applications for incoming notifications locally on your device, enabling you to manage notification logs efficiently.

2. Collected Data & Storage Method

The App collects the following notification items via Notification Access Permission (NotificationListenerService):

  • Collected Items: App Name, Package Name, Notification Title, Notification Text Body, Subtext/BigText, Timestamp, Attached Photo Files.
  • Storage Location & Method: Stored exclusively inside the App's Internal Private Storage, fully encrypted using SQLCipher (AES-256) and AES-256-GCM.

3. Zero Third-Party Sharing & Prohibition of Network Transmission

The App does not share or transmit your personal data to any external parties.

  • The App does not declare or use the Internet permission (android.permission.INTERNET), ensuring network communication is completely blocked at the OS level.
  • No third-party analytics scripts, tracking tools, or advertisement SDKs are included.

4. Security & Safety Measures

The App implements robust security mechanisms to protect your data:

  • Database Encryption: The entire Room SQLite database is encrypted with SQLCipher (AES-256).
  • Media Encryption: Stored notification photos are encrypted using AES-256-GCM.
  • Hardware Key Protection: Encryption master keys are protected within the Android KeyStore hardware security area.
  • Cloud Backup Prevention: allowBackup="false" prevents data extraction via Google Drive cloud backup or ADB backup.
  • Screen Capture Protection: Optional FLAG_SECURE mode prevents screenshots, screen recording, and recent apps preview.

5. Data Deletion & User Rights

Users have full control to manage and destroy their data at any time:

  • In-App Deletion: Instantly delete stored notification logs or photos using the 'Delete' buttons.
  • Auto-Delete Policy: Configure 'Settings > Retention Period' to automatically purge old notification logs.
  • Uninstall Cleanup: Uninstalling the App permanently deletes all encrypted local data.

6. Special Permissions Usage

  • Notification Access (BIND_NOTIFICATION_LISTENER_SERVICE): Used to capture and log incoming notifications locally.
  • Battery Optimization Exception (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS): Used to prevent the background capture service from being killed by OS power saving features.
