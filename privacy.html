NotiMoa (알림모아) 개인정보 처리방침

패키지명: app.noti.moa | 시행일자: 2026년 11월 1일

🔒 NotiMoa는 인터넷 권한(INTERNET Permission)을 사용하지 않습니다. 모든 알림 데이터는 오직 사용자의 스마트폰 내부 암호화 DB에만 저장되며 외부 서버로 절대 전송되지 않습니다.

1. 개인정보의 처리 목적

NotiMoa(이하 "앱")는 사용자가 수신한 알림 내역을 로컬 디바이스에 저장하여 보존, 검색, 통계 분석, 수집제외 앱 관리 등 사용자가 알림 기록을 효율적으로 관리할 수 있는 기능을 제공하기 위해서만 개인정보를 처리합니다.

2. 처리하는 개인정보 항목 및 저장 방식

앱은 알림 접근 권한(NotificationListenerService)을 통해 아래 정보를 수집합니다:

  • 수집 항목: 앱 이름, 패키지명, 알림 제목, 알림 본문 내용, 확장 텍스트, 수신 시각, 첨부 이미지 파일
  • 저장 위치 및 방식: 스마트폰 내부 전용 저장소(Internal Private Storage)에 SQLCipher(AES-256) 및 AES-256-GCM 기술로 완전 암호화하여 저장됩니다.

3. 개인정보의 제3자 제공 및 외부 전송 금지

앱은 사용자의 개인정보를 외부에 제공하거나 전송하지 않습니다.

  • 앱은 인터넷 통신 권한(android.permission.INTERNET)을 선언하거나 사용하지 않으므로 외부 서버와의 통신이 원천 차단되어 있습니다.
  • 어떠한 제3자 서비스(분석 스크립트, 광고 SDK 등)도 포함되어 있지 않습니다.

4. 개인정보의 안전성 확보 조치

앱은 개인정보의 안전성 확보를 위해 다음과 같은 강력한 보안 조치를 적용하고 있습니다:

  • 데이터베이스 암호화: Room SQLite DB 전체를 SQLCipher(AES-256) 알고리즘으로 암호화 처리합니다.
  • 첨부 미디어 암호화: 저장되는 알림 이미지 파일은 AES-256-GCM 알고리즘으로 암호화됩니다.
  • 하드웨어 키보안: 암호화에 사용되는 마스터 키는 Android KeyStore 하드웨어 보안 영역에 보호됩니다.
  • 클라우드 백업 방지: allowBackup="false" 설정을 통해 데이터가 구글 드라이브나 외부 ADB 백업으로 유출되는 것을 차단합니다.
  • 화면 캡처 차단: 앱 화면 미리보기 및 스크린샷 차단 기능(FLAG_SECURE)을 선택적으로 제공합니다.

5. 개인정보의 파기 및 사용자의 권리

사용자는 자신의 개인정보를 언제든지 직접 제어하고 파기할 수 있습니다:

  • 앱 내 직접 삭제: 메인 화면의 '삭제하기' 또는 '사진만 삭제' 기능을 이용하여 저장된 알림 데이터를 즉시 파기할 수 있습니다.
  • 자동 삭제 설정: '설정 > 보존 기간' 기능을 통해 일정 기간이 지난 알림을 자동으로 파기하도록 설정할 수 있습니다.
  • 앱 삭제 시 파기: 앱을 삭제할 경우 기기 내부 Private 저장소에 암호화 보관된 모든 데이터가 시스템에 의해 완전히 삭제됩니다.

6. 특수 권한 사용 안내

  • 알림 접근 권한 (BIND_NOTIFICATION_LISTENER_SERVICE): 수신되는 알림을 수집하여 로컬에 기록하기 위해 사용됩니다.
  • 배터리 최적화 제외 (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS): 백그라운드 수집 서비스가 시스템 절전 기능에 의해 중단되는 것을 방지하기 위해 사용됩니다.
